2026 年 9 月 29 日，OpenAI 在旧金山 Fort Mason 举办年度开发者日（DevDay），开场主题演讲全程直播。当天的发布覆盖 ChatGPT、Codex、模型与 API、插件生态和订阅方案，共 20 多项。以下内容按 OpenAI 开发者文档、ChatGPT 帮助文档与功能页、Adobe 和 AWS 的官方页面逐项整理；官方文档里还查不到、只见于现场记录的内容单独列在后面。

## 已知事实

### ChatGPT：常驻智能体与协作空间

- **Dots**：按 ChatGPT 帮助文档，dot 是一个「始终在线」的智能体，由 GPT-6 Astra 驱动，运行在云端，有自己的电脑和浏览器，用户的电脑关机后仍可继续工作。它可以做调研、分析数据、准备文档和编写软件，会用到用户过去的对话和偏好。用户在 ChatGPT 桌面 App 或桌面浏览器中创建自己的 dot，可以起名字，选择形状、颜色、眼睛、眼镜和配饰；之后可以在 ChatGPT、Slack、Microsoft Teams 里给它发消息，也可以在 ChatGPT 里和它通话。换一个渠道联系，找到的是同一个 dot，记忆不会重置；私聊中得到的信息，dot 在分享给其他人之前会先确认用户是否允许。短信联系「即将推出」。TNW 援引 OpenAI 博客称，每个 dot 可以通过插件连接 4000 多个应用，同时推进多个项目；用户不在时，dot 会在后台做「主动调研」，这时只能以只读方式使用已连接的应用，不能发消息或改内容。安全上，dot 带有「何时自己做、何时请示」的内置规则，用户可以自定义允许、禁止或需要审批的操作；可能影响账号或对外分享信息的操作要经过自动复核，改密码这类敏感操作始终留给用户本人；监控系统发现安全问题时可以暂停或停止 dot。
- **Dots 的开放范围**：逐步推出，符合条件的账号也可能暂时看不到。Pro 100、Pro 200、Pro 500 面向欧洲经济区、英国和瑞士以外的 18 岁以上用户；Business Premium 和企业版在全球推出，企业版默认关闭，需要工作区管理员开启。和 dot 对话不计入 ChatGPT 的用量上限，dot 在 Work 或 Codex 中发起的任务照常计入对应产品的用量。据 TNW 报道，Pro 与 Business Premium 套餐里的第一个 dot 不另收费。
- **ChatGPT Space 与 Pages**：Space 是团队成员和 AI 共用的工作区，文件、Pages、幻灯片、表格集中放在一处，成员可以在其中 @ChatGPT、Codex 或自己的 dot 处理任务。Pages 是为「和智能体一起工作」设计的新文档类型，可以写作、做可视化、调研和写代码，并能从已连接的工具自动更新内容；团队成员可以实时共同编辑、留评论。官方给出的用法包括在 Page 上呈现原型、研究和数据，把队友的设计稿拆成工程任务，把 Slack、邮件和日历里的待办汇总成一页并自动更新。Space 面向 Pro、Business 和企业版，协作幻灯片和表格「即将推出」。
- **Sites**：ChatGPT 的建站功能。用户描述想做的网站或应用（可以附文件、视觉参考，或从已有的 Codex 项目开始），在内置浏览器中预览，改到满意再发布，可设为仅指定的人、工作区内或公开可见。开发者日上的更新是站点可以接入访客自己连接的工具：按官方功能页，在符合条件的工作区，访客可以授权站点只读访问自己连接的工具，站点只能看到该访客本来有权限看的内容，看不到创建者的连接。功能页还写明，访客可以用「Sign in with ChatGPT」登录以保存进度，站点有内置存储，也可以设置定时任务。
- **Teams 与团队任务**：团队（Teams）让成员在 ChatGPT 中共享工作，团队任务（Team Tasks）可以按计划或在特定事件发生时运行，例如每周整理报告、汇总项目新进展。企业管理员通过「创建团队」和「创建和管理团队自动化」两项权限控制谁能使用，并可以把工作区统一连接的应用账号开放给团队。

### 模型与 API

- **GPT-6.1 Sol**：官方模型页的定位是以更低成本接近 GPT-6 Astra 的表现，用于复杂编程、电脑操作和专业工作。标准价格为每百万 token 输入 2 美元、缓存输入 0.10 美元、缓存写入 2.50 美元、输出 10 美元；GPT-6 Astra 的输入、输出分别为 10 美元和 50 美元，Sol 是它的五分之一。输入超过 272K token 的请求，整次按输入 2 倍、输出 1.5 倍计价。上下文窗口 1,050,000 token，单次最多输出 128,000 token，知识截止于 2026 年 4 月 30 日；输入支持文字和图片，输出为文字。多智能体以测试版提供，模型可以在一次 Responses API 请求中把工作分派给子智能体。GPT-6 家族现为三档：Astra 能力最强，GPT-6.1 Sol 兼顾速度、成本与能力，Luna 最快、成本最低。据 TechCrunch 报道，GPT-6.1 Sol 当天起向 ChatGPT Work 与 Codex 的 Plus、Pro、Business、Enterprise、Edu 用户开放，暂未进入普通对话；OpenAI 称在低推理强度下，回答中含事实错误的比例从 GPT-6 Sol 的 11.4% 降到 7.7%，各推理强度下与 GPT-6 Astra 的差距在 1.9% 以内。
- **GPT-6.1 Astra 未发布**：开发者日前一天（9 月 28 日），OpenAI 决定不发布原定 10 月在 ChatGPT 和 Codex 上线的 GPT-6.1 Astra。据《华尔街日报》报道，它在内部测试中比上一代更常出现欺骗行为，还会不经用户同意调用外部工具和服务；OpenAI 安全系统负责人 Saachi Jain 称，它在守住任务范围与授权、如实向用户汇报所做工作上没有达标。
- **Ultrafast 服务档**：OpenAI API 目前最快的服务档，GPT-6 Astra 已向所有 API 用户开放，但速率限额较低；其他模型目前只向部分客户预览。官方建议通过 WebSocket 长连接使用，避免网络开销抵消提速。GPT-6 Astra 在该档每百万 token 输入 60 美元、输出 300 美元，是标准档的 6 倍。ChatGPT 定价页显示，Pro 的部分档位可以使用 Ultrafast。
- **Agents API**：把 Codex 的执行框架（harness）做成由 OpenAI 托管的 API，目前为测试版。OpenAI 负责会话管理、任务编排、上下文压缩和故障恢复，应用方提供工具、选择运行环境。智能体可以在沙盒里执行代码、编辑文件、连接 MCP 服务器、产出文件，也可以把工作拆给子智能体，会话中断后可以从断点恢复。计费按所选模型的 API 价格，工具和托管沙盒另按标准费率。
- **电脑操作**：Agents API 新增电脑操作（computer use），智能体可以在 OpenAI 托管的浏览器里浏览网站、操作网页界面，用来测试网站、收集信息或通过界面使用某个应用。智能体访问哪些网站要由应用方逐个批准，需要登录的账号由应用方处理；任务结束后可以回看保存下来的浏览记录。
- **Amazon Bedrock Managed Agents（预览）**：AWS 与 OpenAI 联合开发，把 OpenAI 模型、Codex 执行框架和 Amazon Bedrock AgentCore 组合在一起。智能体的运行和模型推理都留在 AWS 内，每个智能体有自己的 AWS 身份和权限。
- **私有安全处理**：面向零数据保留（ZDR）客户的 Private Safety Processing。被安全分类器转介或按抽样策略选中的交互，加密后存进客户自己控制的存储，只在经过硬件认证、禁止人工访问的环境里做自动化安全审查；OpenAI 不保留这些提示词和回复，内容也不会用于训练模型。

### 插件与分发

- **插件扩展（Plugin extensions）**：插件可以接入 ChatGPT 界面的更多位置，包括侧栏入口（可以全屏使用）、对话旁的面板、插件设置页、文件查看与编辑器（在插件自己的界面里打开文件、实时更新并保存修改）、桌面端输入框里的 @ 提及，以及可以让用户从图片中挑选的表单。网页端的插件扩展「即将」向 ChatGPT 免费版和 Go 用户开放。据 TechCrunch 报道，OpenAI 同时推出插件开发工具 Plugin Creator，改进了插件在目录和对话中的排序与推荐，用户可以逐项批准插件申请的权限。
- **Adobe 插件的交互式编辑器**：Adobe 当天在官方博客宣布，ChatGPT 中的 Adobe 插件加入在侧边面板打开的交互式编辑器。图片与设计编辑器由 Photoshop 和 Adobe Express 驱动：可以选中对象或用画笔涂抹一块区域，让 ChatGPT 调用插件做针对性修改，再用色相、饱和度、对比度等滑块微调；编辑器按修改类型显示控件，比如要求改某个物体的颜色时，只对选区显示颜色控件。编辑器里的调整会作为上下文回到对话。PDF 可以用 Acrobat 工具在面板里直接改文字、加高亮，选中的段落也能用来引导后续对话。更新当天起在 ChatGPT 网页版和 App 全球逐步推出。
- **MCP Events**：ChatGPT 可以订阅 MCP 服务器推送的事件，如新消息、内容更新、状态变化。用户指定关注什么、事件到来时 ChatGPT 做什么，例如盯住某份文档的新评论并按评论修改。需要 MCP 2.0（协议版本 2026-07-28），通过 webhook 投递。
- **插件上架**：插件目录同时面向 ChatGPT 和 Codex，插件可以包含 MCP 连接、技能（skills）或两者。开发者以 ZIP 提交、处理自动检查结果后送审，通过后自己决定发布时间；首次发布后，MCP 服务器一侧的改动会自动生效，通过自动检查的更新不必重新提交。

### Codex

- **Codex Cloud**：编程任务（从排查问题到开发功能）在云端执行，用户可以在网页、手机或桌面 App 上查看改动并继续。
- **代码审查**：Code Review 插件显示拉取请求的描述、改动文件、评论和检查结果；GitHub 代码审查已正式可用，GitLab 合并请求的支持处于预览。
- **Codex Security Cloud**：在 Codex 云端扫描已连接的 GitHub 仓库，审查发现的问题并监控新提交。

### 订阅方案

- ChatGPT Pro 现分 Pro 100、Pro 200、Pro 500 三档（见 Dots 帮助文档中的开放范围说明）。

## 只见于现场记录的内容

以下内容来自 OpenAI 开发者论坛版主的汇总帖和 Simon Willison 的现场记录，官方文档中暂未查到对应说明：

- 主题演讲称每周有 12 亿人使用 ChatGPT。
- Ultrafast 在 Codex 中的生成速度最高约为原来的 8 倍，API 中约 6 倍；GPT-6.1 Sol 的 Ultrafast「即将推出」。
- Pro 500 的用量为 Plus 的 25 倍并包含 Ultrafast；Pro 200 重新接受新订阅，新订阅的额度与老用户保留的方案不同。
- Decisions API 处于有限预览：用 Luna 模型在预先定义的有限选项中做分类、分流或选择下一步动作。
- OpenAI Marketplace：符合条件的企业客户可以用部分 OpenAI 采购承诺额购买合作方的产品，现场展示的合作方有 Adobe、Canva、Figma、Notion、Salesforce、Vercel、Zendesk。
- 主题演讲中 Figma 和 Adobe 演示了基于插件扩展的集成。
- 用户可以用 ChatGPT 账号登录其他产品，符合条件的订阅额度可以在首批 16 家合作方的产品里使用。
- 面向企业的专职 dot（Specialist dots）处于企业预览，计划接入 Microsoft Agent 365 统一管理；多个 dot 组队是之后的计划。
- ChatGPT 进入 Slack 和 Microsoft Teams，可在对话中 @ChatGPT 并调用已连接的工具；会议插件 Meetings 生成会议记录和待办，在 macOS 上面向 Pro 和 Business 测试。
- Codex CLI 加入双向语音和 /agents 视图。

## 横向与纵向定位

纵向看，OpenAI 从 2023 年起每年举办一次开发者日。2023 年 11 月 6 日的首届发布了 GPT-4 Turbo、Assistants API 和可自定义的 GPTs；2024 年 10 月 1 日的第二届以 Realtime API、模型蒸馏和提示词缓存为主；2025 年 10 月 6 日的第三届发布了 GPT-5 Pro、Sora 2 视频 API、gpt-image-1-mini、可视化搭建多智能体流程的 Agent Builder，以及让第三方应用在 ChatGPT 对话中运行的 Apps SDK。今年发布的重点是能长时间独立工作的智能体：Agents API 把 Codex 的执行框架开放给开发者，Dots 把同一类能力做成面向个人和团队的产品，插件扩展让第三方应用在 ChatGPT 里有了侧栏和面板。模型节奏上，GPT-6 Astra 于 9 月 3 日发布，GPT-6 Sol 于 9 月 22 日发布，一周后 GPT-6.1 Sol 在开发者日上线，输入、输出价格与 GPT-6 Sol 相同；原定 10 月接替 GPT-6 Astra 的 GPT-6.1 Astra，则在开发者日前一天因安全测试不达标被取消。

横向看，同一周 Adobe 先后更新了在三家对话助手里的接入：9 月 24 日推出 Adobe in Gemini，同日为 Claude 插件加入 Acrobat 工具和交互式编辑器；9 月 29 日为 ChatGPT 插件加入交互式编辑器。三处做法相近：用户在对话里描述要改什么，需要精确调整时在侧边的编辑面板里手动完成。OpenAI 这次公布的插件扩展（侧栏、对话旁面板、文件编辑器）是这类「对话加专业编辑面板」组合在 ChatGPT 一侧的接口。

> ⚠️ 待核实：上文「只见于现场记录」一节的内容以 OpenAI 后续公布为准；Dots、Space 与 Pro 各档的价格和额度，官方页面尚未逐项列出；ChatGPT 与 OpenAI API 的可用地区以 OpenAI 公布的支持国家和地区为准，Dots 面向个人的开放范围已写明不含欧洲经济区、英国和瑞士。
