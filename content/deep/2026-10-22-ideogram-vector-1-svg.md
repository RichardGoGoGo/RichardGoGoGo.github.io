2026 年 10 月 22 日，Ideogram 在官方 X 账号宣布推出该公司首个矢量模型，称它能从文字提示生成带平滑渐变和清晰文字排版的可编辑 SVG，或把任意图像转成细节丰富、可缩放的矢量图，当天已在 Ideogram 应用和 API 上线。官网模型页的名称为 Ideogram Vector，API 模型 ID 为 `ideogram-vector-1`；媒体报道中多称 Vector 1.0。以下内容按官方 X 公告、官网模型页和 API 文档整理。Ideogram 官方博客目前没有单独的发布文章，也未见主流科技媒体报道。

## 已知事实

### 两条路径

- **文生矢量（Text to vector）**：用文字描述设计，参考图可选。API 端点为 `POST /v2/svg/generate/ideogram-vector-1`，可设长宽比、质量档位、生成数量和随机种子，可传多张参考图，第一张作为主要来源。
- **图转矢量（Image to vector）**：上传现有图像直接转换，不需要提示词。API 端点为 `POST /v2/svg/vectorize/ideogram-vector-1`，接受 JPEG、PNG、WEBP，最大 50MB；提供两种模式，简单模式用更少、更简单的形状，默认模式保留更多细节。
- 两个端点都是异步返回生成 ID，再查询结果，也支持 webhook 回调；可用 `dry_run` 参数先报价不生成。

### 官方描述的输出特性

- 模型页称输出为可缩放、可编辑的 SVG，可放大到海报尺寸保持边缘清晰，可整体换色以匹配品牌色，可在矢量编辑器中单独选中和修改某个形状。
- 官方示例的用途包括文字排版、插画、标志与品牌、印刷与周边、标签与贴纸。
- 官方没有点名支持的设计软件，只说可导入矢量编辑器继续修改。

### 价格（API，按每个 SVG 计）

| 路径 | 档位 | 仅提示词 | 带参考图 |
|---|---|---|---|
| 文生矢量 | 低 | 0.13 美元 | 0.13 美元 |
| 文生矢量 | 中 | 0.16 美元 | 0.16 美元 |
| 文生矢量 | 高 | 0.20 美元 | 0.32 美元 |
| 图转矢量 | — | 0.10 美元/张 | — |

在 Ideogram 应用内使用时按订阅套餐或点数计，模型页未单独列出应用内的消耗。

### 当前限制

- API 的图转矢量端点有 `group` 参数（把形状分组成图层），文档注明分组功能尚不可用，因此转换结果中的形状目前不会自动按对象分层。
- API 文档的矢量部分只有生成和转换两个端点，没有对已生成 SVG 做局部修改的端点，修改需在外部矢量编辑器中完成。
- 目前没有独立测评。输出的路径数量、锚点是否精简、分组是否符合设计师习惯，这些都需要实际导出文件检查。

## 横向与纵向定位

纵向看，Ideogram 此前以图像模型为主（3.0、4.0、4.5），矢量模型是新增的一条产品线，在官网模型菜单中与这些图像模型并列，API 中也单独设了 SVG 端点。

横向看，AI 生成矢量并非新方向。Recraft 的 API 已提供矢量插画风格的生成和图像矢量化端点。Ideogram Vector 的不同之处在于它是 Ideogram 自家专门输出 SVG 的模型，并沿用 Ideogram 在文字排版上的定位。对做标志、图标、贴纸和印刷周边的设计者来说，实际价值取决于导出的 SVG 在 Illustrator、Figma 等工具中需要多少清理，这一点要等实测。
