## 一、分环节工具地图：Kling 集中退役旧模型，Runway/Figma/Vidu 各有新动作

**Kling AI（可灵）**：**2026-09-15** 为官方公布的旧模型迁移截止日，官方集中下线 10 个旧版本模型、整条早期 API 及 119 个特效模板（含虚拟试穿等）。仍在用 Kling 旧版本做教学演示案例的教师需要同步更新工具清单与操作指引。

来源：两个独立信源交叉核实（模型退役追踪聚合页 + 媒体报道），⚠️官方公告页面本轮未能直接打开核对。

**Runway**：Dev API 于 **2026-09-17** 上线「Enhance Frame Rate」帧率增强功能，可将视频转换为 24/25/30/48/50/60/120 等目标帧率，按输入时长计费（约 1 credit/2 秒），最高支持 120fps。适合"出视频"环节讲解视频后期规格化处理的教学演示。

来源：Runway Dev API Changelog（官方聚合页）+ 两家独立报道交叉核实。

**Figma**：**2026-09-17** 官方博客宣布 Figma Design 与 Figma Weave 工作流打通新增"Figma node"节点——可将 Design 中的画板直接复制为 Weave 工作流节点，保留字体/排版/样式，文本与图片图层可作为工作流输入并与原设计实时同步。可用于"调研/出图"环节演示"已有设计资产 → AI 生成工作流"的衔接教法。

> ⚠️ 待核查：官方博客原文本轮因网络出口限制未能直接打开核对，以上信息基于两次独立检索均指向同一官方链接与日期得出，建议教师采用前自行核对 figma.com/blog/connecting-figma-and-weave/。

**Vidu**：生数科技官方新闻稿称 **2026-09-15** 发布 Vidu S2，含 S2-Avatar（语音实时交互数字人，720p+、25–42fps）与 S2-Editing（直播流实时编辑）。可作为"出视频"环节展示实时 AI 交互工具教学演示可能性的新案例。

> ⚠️ 待核查：本条目前仅见同一新闻通稿被多平台转载，尚未找到独立信源交叉印证，具体规格与发布日期请以生数科技官方渠道为准。

**Midjourney**：Alpha Changelog（2026-09-16）显示 V8.2 编辑器持续小版本迭代——新增韩语界面、草图批量生成改为网格预览+"Enhance"按钮、编辑器内"添加到文件夹"支持无文件夹场景。此为此前已收录的 V8.2 Edit 功能的渐进更新，非全新发布，仅作为工具地图的补充记录。

来源：Midjourney 官方 Alpha Changelog（通过检索摘要读取，⚠️未直接核对原文）。

来源合集：[Runway Dev API Changelog](https://docs.dev.runwayml.com/api-details/api_changelog/)、[Figma 官方博客 · Connecting Figma and Weave](https://www.figma.com/blog/connecting-figma-and-weave/)、[Midjourney Alpha Changelog](https://updates.midjourney.com/)
