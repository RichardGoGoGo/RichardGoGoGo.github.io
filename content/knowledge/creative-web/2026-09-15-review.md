## 一、动效实现手法与库：Motion v13.3.0 大幅性能优化

Motion（npm 包 `motion`）发布 **v13.3.0**，npm registry 时间戳直接核实为 **2026-09-14**。本次更新以性能优化为主：`useSpring`/`springValue` 的 retargeting 耗时降低约 80%，`animate` 体积减小约 10%，启动耗时降低约 20%，渲染耗时视场景降低 10%～60%，帧调度速度提升约 10%，另修复一处 path 绘制计算 bug；同时新增若干与 Motion Editor 配套的 hooks。GSAP 经 npm registry 核实仍为 3.15.0，本期无更新。

来源：[npm · motion](https://www.npmjs.com/package/motion)（registry 时间戳直接核实）；[motion CHANGELOG.md](https://github.com/motiondivision/motion/blob/main/CHANGELOG.md)

## 二、常用组件/交互模式：React Bits 三处修复，含无障碍回归收尾

GitHub 直接核实 `github.com/DavidHDev/react-bits` 的 commit/PR 记录：

- **PR #1068（合并于 09-10）**：修复 `DecryptedText` 组件的屏幕阅读器专用（sr-only）参考文本，在部分 Tailwind 变体下仍会被视觉可见——这是上期综述提到的那处无障碍回归（PR #1067）的收尾修复。
- **PR #1070（合并于 09-11）**：修复 `LetterGlitch` 组件设为 "smooth" 颜色渐变模式时只执行一帧就冻结的 bug，原因是 RGB 插值与 CSS 字符串格式化逻辑相互干扰导致解析失败。
- **提交 `ebe0513`（09-11，对应 PR #1065 后续）**：修复 `TextLoop` 组件在 Firefox 下 SVG 文字被裁切不一致的问题——默认示例文案含重复分隔符，导致 `textLength`/`lengthAdjust` 计算错位。

来源：[PR #1068](https://github.com/DavidHDev/react-bits/pull/1068)、[PR #1070](https://github.com/DavidHDev/react-bits/pull/1070)、[PR #1065](https://github.com/DavidHDev/react-bits/pull/1065)（均 GitHub 直接核实）

## 三、视觉风格与设计到代码：Codrops 两篇实战案例

- **《Yestalgia：用充满趣味的数字体验重现 Decathlon 的 90 年代精神》**（2026-09-12，多方独立信源交叉核实，同一项目同步收录于 Awwwards Site of the Day）：技术栈拆解——GSAP + ScrollTrigger 驱动叙事式滚动、Lenis 平滑滚动、Tempus 统一管理跨库共享的动画循环、piecesjs web components 组织可复用视觉片段，整体走 90 年代磁带播放器式导航的复古美学路线，是"高完成度做法"子领域的一个新范例。
- **《Building Depth：在 Figma 内设计并开发一个 3D 渲染器》**（2026-09-13，多方独立信源交叉核实）：作者 Aleksei Kipin 开发的 Figma 插件 "Depth"，把实时 Three.js 渲染器直接嵌入 Figma 画布——设计师可在 Figma 内加载 3D 模型、调相机与灯光、直接导出 PNG，不必再跳出 Figma 用 Blender/Cinema 4D 来回倒腾，是"设计到代码"子领域里"设计工具原生集成 3D/动效能力"的一个具体样本。

来源：[Codrops · Yestalgia](https://tympanus.net/codrops/2026/09/12/yestalgia-bringing-decathlons-90s-spirit-to-life-through-a-playful-digital-experience/)；[Codrops · Building Depth](https://tympanus.net/codrops/2026/09/13/building-depth-designing-and-developing-a-3d-renderer-inside-figma/)（Codrops 原文本轮被检索环境拦截，以上信息经多方独立信源交叉核实标题、日期、要点）
