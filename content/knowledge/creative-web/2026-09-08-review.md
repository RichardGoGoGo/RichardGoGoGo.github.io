## 一、动效实现手法与库：Motion v13.2.0 首次直接驱动 Three.js / WebGPU 场景对象

**Motion（motion.dev）v13.2.0** 于 **2026-09-02** 发布（npm registry 时间戳直接核实：`2026-09-02T15:25:47.792Z`），新增：

- `animate.addEffect()`：让 `animate` 可以驱动非 DOM 对象。
- `threeEffect`（`motion/three`）：支持直接驱动 Three.js 对象、材质、shader uniform、TSL uniform 节点。
- `vgpuEffect`（`motion/vgpu`）：支持共享 uniform、绑定、场景节点、相机、灯光、材质、轨道控制、颜色/向量组件，面向 WebGPU 场景。

这是 Motion 首次把动画系统直接接入 Three.js / WebGPU 场景对象，而不再局限于 DOM 元素——对"用 Motion 驱动 3D/Shader 场景"这类高完成度创意站点是本期最重要的一条更新。

来源：[Motion CHANGELOG v13.2.0](https://raw.githubusercontent.com/motiondivision/motion/v13.2.0/CHANGELOG.md)、[GitHub Release](https://github.com/motiondivision/motion/releases/tag/v13.2.0)、npm registry 官方 API 时间戳核实（2026-09-02）

GSAP 本期无新版本——npm registry 直查最新仍为 3.15.0（2026-04-13 发布），跳过。

## 二、常用组件/交互模式：React Bits 两周新增 5 个组件，完成文档改版与浅色模式

**React Bits**（github.com/DavidHDev/react-bits）本窗口密集更新，均经 GitHub commit/PR 页面直接核实：

- **Glow Cursor**（鼠标跟随光轨）+ **CRT Warp**（指针交互式 CRT 等离子畸变，含扫描线与辉光）——**2026-08-26**。
- **文档大改版 + 浅色模式（light mode）**上线，落地页组件（Navbar/Hero/Features/Footer 等）同步重做——**2026-08-28**。
- **Infinite Spiral**（无限循环 3D 螺旋图片墙）+ **Ghost Fibers**（深蓝递归光纤场背景）——**2026-08-29**，同批修复 Hyperspeed（弃用的 Three.Clock）、Shuffle（竖排字形裁切）等既有组件问题。
- **AeroShards**（GPU 驱动折纸箔片群，"content-safe placements"——背景效果自动避让正文区域，响应式指针交互）——**2026-08-31**。

对建站的启发：AeroShards 的"content-safe placements"是一个值得直接借鉴的具体设计手法——把"背景动效不能盖住正文"这条经验规则做成了组件自带的自动避让逻辑，而不是靠人工调 z-index 和留白试错。

来源：[React Bits commit a689d0e](https://github.com/DavidHDev/react-bits/commit/a689d0e)（Glow Cursor / CRT Warp，08-26）、[commit 1b252c1](https://github.com/DavidHDev/react-bits/commit/1b252c1)（文档改版/浅色模式，08-28）、[commit a81bfc3](https://github.com/DavidHDev/react-bits/commit/a81bfc3)（Infinite Spiral / Ghost Fibers，08-29）、[commit 559c74c](https://github.com/DavidHDev/react-bits/commit/559c74c)（AeroShards，08-31）

## 三、性能/无障碍/响应式：Safari TP 251 新增排版特性；React Bits 一处无障碍回归待跟进

**Safari Technology Preview 251**（**2026-08-26**）⚠️新增 `@supports at-rule(...)` 语法支持、`object-view-box` 属性、`@container` 查询支持逗号分隔的多条件组合、Canvas 面板新增 WebGPU 设备录制与内容预览支持。官方页面本轮检索环境无法直接打开逐字核对，内容经多方搜索结果交叉确认，标注待核实。

**React Bits `DecryptedText` 组件无障碍回归**（PR #1067，**2026-09-05**）：该 PR 修复了"参照文本可见"的显示 bug，改用 `visibility: hidden` 隐藏参照文本，但代码审查已指出这一改法**可能移除无障碍树中唯一非 `aria-hidden` 的文本，导致屏幕阅读器读不到内容**，维护者仍然合并。这是一个值得在"性能/无障碍/响应式"子领域记录并持续跟进的技术债样本——视觉修复与无障碍语义可能互相冲突，值得作为建站方法论里的一条反面案例。

来源：[WebKit · Safari Technology Preview 251 Release Notes](https://webkit.org/blog/18194/release-notes-for-safari-technology-preview-251/)（2026-08-26）；[React Bits PR #1067](https://github.com/DavidHDev/react-bits/pull/1067)（2026-09-05）
