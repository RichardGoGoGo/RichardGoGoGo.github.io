上海交通大学 A2Edit 提出任意对象参考图像编辑方法（Arbitrary Object Reference Editing），无需用户手动绘制掩码，通过输入参考图自动定位并替换目标对象，支持外观迁移与风格一致性保持；论文被 ECCV 2026 收录。该方法降低了精准图像编辑的操作门槛，为参考驱动的内容替换提供端到端方案。

> 无掩码参考编辑将"提供一张参考图+选定目标"作为完整的编辑指令，对电商图像替换、广告创意迭代等高频编辑场景有直接的工程转化价值。
