JarvisHub（arXiv 2607.23588，开源 GitHub MIT License）提出以「可编辑画布」同时充当 Agent 工作空间、外部记忆与动作空间的三层统一架构，支持文本/图像/视频/音频跨模态持续规划、迭代编辑与版本管理；用户可随时介入、引导、检查 Agent 创作进程，是首个以画布而非对话框为第一公民的多模态创作 Agent 框架。

> 将画布从输出界面提升为 AI 协作统一工作台，直接对应设计师的工作习惯，为 AI 辅助多模态创作工作流的架构设计提供了新的方法论参照。
