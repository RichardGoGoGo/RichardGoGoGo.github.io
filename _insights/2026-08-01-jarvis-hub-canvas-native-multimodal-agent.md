JarvisHub 以开源形式发布画布原生多模态 Agent 框架，将工具调用、视觉感知与多步骤任务规划能力统一于交互式画布界面；Agent 可在画布上感知、操作和生成多模态内容，支持复杂工作流的可视化规划与自动执行。论文同步发布于 arXiv，代码开源于 GitHub。

> 画布原生 Agent 将过去分散在对话框与工具面板中的操作整合为统一的视觉交互空间，对 AI 辅助创意工作流和多模态内容生产的工具设计有参考意义。
