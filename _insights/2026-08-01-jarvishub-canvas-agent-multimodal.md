JarvisHub 将可编辑画布同时作为 Agent 工作区、外部持久记忆与动作空间，通过三层架构（感知层/规划层/执行层）实现多模态长程创作中的持续规划、迭代编辑与版本管理；已在 GitHub 开源，支持图像/文本/代码多模态输入。

> 开源画布原生 Agent 框架，设计×AI 课题中"可交互、可迭代的 AI 创作工作流"方向的方法论参考，教师可将 JarvisHub 作为"AI 如何辅助完整设计项目而非单步生成"的学术案例引入研讨课。
