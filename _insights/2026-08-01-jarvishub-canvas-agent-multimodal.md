JarvisHub（arXiv:2607.23588）提出一种以"画布即工作区"为核心设计理念的多模态 Agent 框架：Agent 在持久化画布上进行感知、规划与执行，画布状态同时充当短期记忆载体与跨步骤上下文锚点；动作空间涵盖文本生成、图像操作、代码执行与外部工具调用，三者通过统一接口与画布状态双向交互。与将记忆和动作独立存储的传统架构相比，该设计减少了跨模块的状态同步开销，在多轮视觉推理任务上的完成率有所提升。框架代码已全量开源。

> JarvisHub 将画布作为 Agent 统一工作记忆的架构思路，为构建支持长程多模态任务的 Agent 系统提供了一种值得参考的工程范式。
