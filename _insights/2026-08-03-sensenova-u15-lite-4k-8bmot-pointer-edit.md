商汤开源 SenseNova U1.5-Lite-Preview（8B 参数 Mixture-of-Transformers 轻量统一多模态模型），核心能力：原生 4K 图像直出（不依赖后处理上采样）、红框/marker 标注「指哪改哪」精准局部编辑、复杂信息图与海报多图参考合成；Qwen-Image-Bench 综合评分从 47.14 升至 55.20，5+ 主流媒体同日报道，权重、demo 与 API 全面开放于 GitHub/HuggingFace/ModelScope。

> 8B 轻量参数的原生 4K 生成与精准局部编辑组合，大幅降低了本地部署门槛，「指哪改哪」机制对信息图、海报、版式设计等创作场景具有直接的工具价值。
