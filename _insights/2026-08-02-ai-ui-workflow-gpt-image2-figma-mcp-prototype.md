设计师风筝 KK 完整实测"文字需求→草图→Figma 高保真→前端代码→移动端预览"全链路 AI×UI 工作流：GPT Image 2 负责生图（采用插图分层模式），Figma MCP Agent 完成设计结构自动对齐，WorkBuddy 生成可用前端代码，最终在移动端完成预览验证；实测证明"插图分层+页面结构合并"是目前 AI×UI 工作流还原质量最优解。

> 全链路实测将 AI×UI 从概念落地为具体操作步骤，各环节工具选型及接口逻辑清晰，可直接拆解为多课时 UI/交互设计课程的 AI 工具实操教案。
