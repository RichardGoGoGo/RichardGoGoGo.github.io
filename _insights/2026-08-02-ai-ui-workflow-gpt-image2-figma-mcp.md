优设梳理了将 GPT Image 2 与 Figma MCP 结合使用的 AI UI 设计工作流：利用 GPT Image 2 根据产品描述生成界面视觉稿，通过 Figma MCP 将生成结果直接导入 Figma 设计系统进行组件映射与标注，再经过交互逻辑补全完成可提交原型；文章附提示词结构（包含设备平台、配色约束、组件风格、信息层级等维度）及各环节的具体操作路径与注意事项。

> GPT Image 2 与 Figma MCP 的直连工作流将 AI 图像生成结果与设计交付物之间的人工转化步骤大幅压缩，对需要快速输出高保真原型的 UI 设计团队具有即时效率价值。
