Anthropic 工程师 Thariq Shihipar 解释了 Claude Code 为 Opus 5 / Fable 5 删除约 80% 系统提示词的原因：旧规则是为旧模型写的，新模型已能根据代码自行判断；上下文工程的重点从堆叠规则转向交代产品环境与目标，并按需加载 Skills、工具与资料。

> 给 AI 写说明的方式随模型能力变化：与其罗列规则，不如交代清楚环境与目标，用 AI 辅助设计工作流时同样适用。
