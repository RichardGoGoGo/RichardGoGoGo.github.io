Anthropic工程师Thariq Shihipar详解Claude Code为Opus 5/Fable 5删除80%系统提示词的原因：旧规则是为旧模型准备的，新模型可根据代码自行判断；上下文组织从「堆规则」转向「交代产品环境与目标」，Skills/工具/资料按需加载；范式级转变：以前给AI喂规则，现在给AI塑造认知语境。

> 直接影响所有AI辅助设计工作流的Prompt工程实践——告别「写满规则的系统提示词」转向「让模型理解环境」，对设计师/研究者使用Claude辅助工作有范式级参考价值；工作坊可用来讲「如何给AI配置工作环境而非堆砌规则」。
