Anthropic工程师Thariq Shihipar详解Claude Code为Opus 5/Fable 5删除80%系统提示词的原因：旧规则是为旧模型设计的，新模型已能根据代码自主判断；上下文工程从"堆规则"转向"交代产品环境与目标"，按需加载Skills/工具/资料；这是一次范式级转变——以前给AI喂规则，现在给AI塑造认知语境。

> 对用AI辅助设计工作流的人来说，这意味着写Prompt的方式需要根本性转变。
