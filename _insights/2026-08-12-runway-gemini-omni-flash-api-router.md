Runway于8月12日推送两项更新：① 付费套餐用户可使用Google Gemini Omni Flash从提示词/图像/视频生成与编辑内容，提供第二模型选择；② API新增Model Router，支持跨视频/图像/音频模型的无模型路由，可配置成本/延迟/质量偏好及模型黑白名单；企业版同步新增用量导出与审计日志。

> API Model Router的引入使开发者可以在不修改代码的情况下智能切换底层模型，降低了多模型工作流的集成复杂度。
