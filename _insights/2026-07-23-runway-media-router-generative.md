Runway 发布 Media Router，定位为首个专为生成式媒体设计的模型路由器：创作者设定质量、速度、成本优先级后，系统自动在 Gen-4.5、Aleph 2.0 等模型间选择最优路径；企业用户可在预算内最大化生成质量；主要面向 Runway Dev API 生态。

> 「模型路由」是 AI 内容生产工业化的关键基础设施概念——从手动选模型到按任务需求自动分配最优资源，是 AI 工具生态走向成熟的重要信号。
