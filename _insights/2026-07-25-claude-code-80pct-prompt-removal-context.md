2026年7月25日，Anthropic工程师Thariq Shihipar详解Claude Code为Opus 5/Fable 5删除80%系统提示词的原因：旧规则是针对旧模型能力边界设计的，新模型可根据代码语境自行判断行为；上下文组织从"堆积规则"转向"交代产品环境与目标"，工具、技能与资料按需加载。

> AI模型能力提升正在改变提示词工程的基本范式，从规则枚举转向环境说明，为构建基于大模型的AI系统提供了重要的工程实践参考。
