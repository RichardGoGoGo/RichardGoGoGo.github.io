据 X 平台流传的前后对比截图，Anthropic 对 Claude Code 的内置系统提示词进行了大规模精简，移除了大量重复的行为约束条款、格式说明与工具使用指导，保留核心安全边界与角色定义，整体篇幅缩减约 80%。此次调整意味着每次对话的固定 token 消耗显著降低，对于依赖长代码库上下文的工程任务，可用于历史消息与代码引用的窗口空间相应扩大，长会话中的指令遗失问题也有所改善。

> 系统提示词的大幅压缩直接影响 Claude Code 在长会话、大代码库场景下的实际可用上下文容量，是提升复杂工程任务完成率的工程层优化手段。
