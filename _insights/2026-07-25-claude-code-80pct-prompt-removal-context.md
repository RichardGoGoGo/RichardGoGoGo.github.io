Anthropic工程师Thariq Shihipar详解Claude Code为Opus 5/Fable 5删除80%系统提示词的原因——旧规则是为旧模型准备的约束，新模型具备更强的自主判断能力，可根据代码环境自行推断意图；上下文组织策略从「堆叠规则」转向「交代产品环境与目标」，Skills/工具/资料按需加载而非一次性塞满。

> 这一变化揭示了上下文工程的成熟方向：不是给模型更多约束，而是给模型更好的环境理解——模型能力越强，系统提示词应越精简、越聚焦意图而非程序性规则。
