Anthropic将Claude Code的系统提示词规模大幅削减约80%，从大型综合提示词转向精简的上下文工程策略，此举引发AI工程社区对"提示词膨胀"问题的广泛讨论；相关观察者指出，精简系统提示词配合更清晰的上下文结构，可能在保持任务表现的同时降低token消耗和推理延迟。

> 大型AI工具从"提示词堆砌"转向精简上下文工程的实践，为AI工具开发者和研究者在提示词设计与系统集成方面提供了来自头部产品的经验参照。
