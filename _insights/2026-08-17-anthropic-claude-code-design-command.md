Anthropic于8月17日在Claude Code开发工具中推出/design命令研究预览版：开发者在编码会话中通过自然语言描述界面需求，/design命令生成对应的UI画板（设计规格），画板可直接导入代码流，实现"设计描述→UI画板→代码实现"的无缝衔接。这一功能与Figma MCP、Lovable、v0等AI原生设计路径形成差异化，定位于以代码为主要工作语言的开发者群体。同期Anthropic还上线了"Claude for Creative Work"，支持接入Adobe/Canva/Blender等创作工具。

> /design命令与"Claude for Creative Work"形成互补：一端面向开发者（编码→设计），一端面向创作者（设计→内容），Claude正在从纯文本模型向覆盖设计链路两端的创作平台延伸。
