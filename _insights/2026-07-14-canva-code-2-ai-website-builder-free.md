Canva 发布 Code 2.0，将 AI 代码生成功能向全部 2.65 亿月活用户（含免费层）全量开放；用户可通过自然语言提示生成完整响应式网站或应用，支持 HTML 导入、50 余种模板，生成速度较前代提升 75%，从提示到上线的时间压缩约 30%。

> Canva Code 2.0 免费化意味着设计类用户可直接将 Canva 视觉方案转为可运行网站原型，无需手写代码，进一步压低 AI 辅助原型制作门槛。
