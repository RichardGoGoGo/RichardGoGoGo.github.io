继 10 月中旬全量上线旗舰模型 Kling 4.0 后，快手可灵于 2026 年 11 月 4 日宣布将轻量高速版本 Kling 4.0 Flash 解除年度会员专属限制，面向全体网页端用户开放，并同步上线公共 API、命令行接口及创作套件插件。Kling 4.0 Flash 针对高频概念测试与分镜预演优化，支持文生视频、图生视频与 Omni Reference 多模态参考控制，单次可生成 3 至 20 秒的 720p 视频片段，API 定价约为每秒 0.094 美元，并支持在 Adobe Photoshop、Premiere Pro、After Effects 及 Krea 等多模型工作台中直接调用。

> 继旗舰版 Kling 4.0 之后，面向高频迭代的轻量版全面放开 API 与后期软件插件，便于在正式高分辨率渲染前低成本验证分镜与动作。
