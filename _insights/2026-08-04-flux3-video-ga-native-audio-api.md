Black Forest Labs 于 2026 年 8 月 4 日正式发布 FLUX 3 Video，标志着 FLUX 系列从图像生成正式扩展至视频领域。核心能力包括：单次最长生成 20 秒视频并支持原生同步音频生成（无需后期配音）；原生 1080p 分辨率输出；提供 Draft（$0.06/秒）与 Pro（定价更高）两档 API 接入，Draft 版面向快速原型与批量生成场景。模型同步通过多家主流 AI 平台 API 路由接入。

> FLUX 3 Video 以原生音视频同步生成打破了此前视频生成与音频生成分离的工作流割裂，其 Draft 版的低价 API 接入也大幅降低了大规模 AI 视频内容生产的成本门槛。
