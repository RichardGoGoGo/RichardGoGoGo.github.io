北京于 2026 年 7 月发布推动人工智能 Agent 发展的十项举措，内容涵盖 Agent 基础能力标准制定、典型应用场景优先开放、多模态感知接口规范、工具调用安全沙箱要求，以及针对自主行动类 Agent 的人机协同机制与审计日志强制记录等约束性条款；文件同步部署 Agent 监管沙盒与合规认证通道，为北京地区 Agent 商业化部署提供政策依据。多项条款直接对接工业、医疗、政务等垂直场景的 Agent 应用准入标准。

> 这是国内首份针对 Agent 工程化落地的城市级专项政策，其技术标准与安全约束框架将直接影响相关企业的产品合规路径选择。
