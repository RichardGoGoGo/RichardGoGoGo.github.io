Black Forest Labs 于9月15日推出 FLUX Video Edit API，计费标准为 $0.03/秒输出。该 API 接受源视频与文字描述，可精准修改视频中指定元素（换服装、替换背景、改变材质等），同时完整保留原片运动轨迹与音频；已通过 ComfyUI v0.36.0 原生节点接入，亦支持直接调用 BFL API，底层能力与 FLUX 图像模型家族共用。

> 「改元素不改运动」解决了 AI 视频二次编辑中时序一致性的核心痛点，$0.03/秒的低单价使教学实操场景的成本具体可控。
