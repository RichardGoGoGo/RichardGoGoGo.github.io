上海交通大学研究团队提出A²-Edit（Any-to-Any Object Reference Editing），该方法允许用户将任意目标物体图像作为参考，驱动对目标图像中对应元素的外观、材质或风格进行精确编辑，无需针对特定物体进行额外训练或微调；研究结果表明该方法在多类别物体的参考编辑任务上超越现有基线方法。

> 任意物体参考驱动编辑方法降低了高精度图像定制编辑的使用门槛，在产品设计原型、角色创作和品牌视觉替换等应用场景中具有实用前景。
