OpenAI 于 8 月 12 日宣布 DALL-E 系列及 GPT-4o 旧版图像生成 API 正式退休，现有图像生成能力统一迁移至 ChatGPT Images 入口；依赖旧版 DALL-E API 的第三方应用需按计划完成迁移。此举标志着 OpenAI 图像生成产品线完成整合，由分散的独立模型入口收束为统一接口。

> DALL-E 退休是 OpenAI 产品线整合的节点事件，对依赖旧版 API 的工具和集成方案有明确的迁移截止压力，需关注官方迁移指南与时间表。
