Black Forest Labs 于 2026 年 8 月 4-5 日正式开放 FLUX 3 Video API：支持生成最长 20 秒、1080p 原生分辨率视频，音频与画面同步生成（native audio），无需后期配音；支持文生视频、图生视频、视频续帧及关键帧过渡四种模式；FLUX 3 Image 独立接口及开源权重（FLUX 3 Dev）仍在发布队列；这是 FLUX 系列从"图像生成"到"视听一体内容生产"的正式落地，标志着 FLUX 生态向完整多模态内容创作平台演进。

> FLUX 3 Video API 全量开放将 AI 视频创作从"预告"变为"可动手练"，对设计工作营"AI 视频生成"单元是直接升级素材，教师和学生现在就能通过 API 跑通带声音的短片工作流。
