实操教程：通过Claude Code搭建设计系统（Design System），将组件规范、颜色变量、间距规则等结构化输入AI，让UI生成从「每次碰运气」变为「按规则稳定输出」，解决AI生成UI界面一致性差的核心痛点；提供完整操作流程和提示词模板。

> 将结构化设计规范输入AI的方法论将AI生成UI的不确定性转化为可控输出，为「AI辅助UI设计」从实验性工具升级为专业工作流提供了可复现的技术路径。
