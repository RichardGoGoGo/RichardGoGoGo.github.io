一名设计师分享了将GPT-4o Image Generation 2与Figma MCP服务器结合的完整UI设计工作流：通过自然语言描述生成界面草图，经MCP协议导入Figma自动布局，再借助代码生成插件输出可预览的前端组件，全流程无需手工切图或标注。

> 该工作流将AI图像生成与设计工具直接打通，为UI生产提速提供了可复现的端到端范式。
