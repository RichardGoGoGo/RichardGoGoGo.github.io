阿里Qwen-Image-3.0于8月5日开放公开API（仅API，无开源权重，无公开基准测试报告）。模型支持最长4500 token提示词，可原生渲染12种语言×20+字体，生成公式符号、几何形状、逻辑推理布局等复杂知识图谱和UI界面，单次生成最多9张图。Qwen团队自称中国图像模型第一、全球第二（仅次于OpenAI GPT Image 2），模型已上线阿里云灵积API平台。

> Qwen-Image-3.0的12语言原生文本渲染与复杂信息图生成能力，填补了此前中文AI图像模型在排版密度与跨语言文字精度上的短板。
