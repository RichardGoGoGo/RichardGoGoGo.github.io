阿里巴巴于 2026 年 8 月发布 Qwen Image 3.0 图像生成模型并开放 API 访问，此次发布未附 Qwen Image 2.0 时公开的评测基准分数与模型权重，转而以 API 形式直接面向商业用户提供服务。官方介绍的能力亮点包括文本渲染精准度提升、多轮编辑指令跟随能力增强，以及对中文场景与东亚视觉风格的优化；模型定价按 API 调用量计费，具体价格通过阿里云控制台公开。

> Qwen Image 3.0 跳过基准公开与开源权重直接走商业 API 路线，标志着阿里巴巴图像生成产品策略从开源社区建设转向直接商业变现，与同期 Qwen 语言模型的开源策略形成明显分化。
