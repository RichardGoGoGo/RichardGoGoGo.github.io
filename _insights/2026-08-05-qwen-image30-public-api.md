阿里云于2026年8月5日通过Model Studio向开发者开放Qwen Image 3.0 Pro的公开API访问。该模型支持图像理解与生成双向能力，在文档解析、图表分析及图像描述生成等任务上相比前代模型有显著提升，定价按token计算。

> Qwen Image 3.0 Pro的公开API开放为国内外开发者提供了具备竞争力的多模态图像模型选项，有助于多模态应用生态的多元化。
