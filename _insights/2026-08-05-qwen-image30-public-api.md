阿里Qwen-Image-3.0于8月5日开放公开API（仅API，无开权重，无基准报告），支持最长4500 token提示词，原生渲染12语言×20+字体，生成公式符号、几何形状、逻辑推理布局等复杂知识图谱和UI；单次生成最多9张图。自称中国图像模型第一、全球第二（仅次于OpenAI GPT Image 2）。

> 12语言文本渲染+复杂信息图能力，对海报/学术信息图制作方向课程有即时价值；与SenseNova U1.5-Lite-Preview同期竞争，可作为国产图像生成能力横向对比的参照案例。
