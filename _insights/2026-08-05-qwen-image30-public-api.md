2026年8月5日，阿里Qwen-Image-3.0开放公开API（仅API，无开权重，无基准报告），支持最长4500 token提示词，原生渲染12语言×20余种字体，可生成公式符号、几何形状、逻辑推理布局等复杂知识图谱和UI；单次生成最多9张图；自称中国图像模型第一、全球第二（仅次于GPT Image 2）。

> 原生多语言排版与复杂知识图谱生成能力，是Qwen-Image-3.0的差异化定位，但无基准报告与开权重的发布方式使独立评估受限，实际效果仍需以具体任务对照检验。
