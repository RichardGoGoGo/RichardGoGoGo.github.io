阿里Qwen-Image-3.0于8月5日开放公开API（仅API，无开源权重）。支持最长4500 token提示词，原生渲染12语言×20+字体，生成公式符号、几何形状、逻辑推理布局等复杂知识图谱和UI；单次生成最多9张图；自称中国图像模型第一、全球第二（仅次于GPT Image 2）。

> 12语言原生文本渲染与复杂信息图生成能力，为多语言创意内容生产和中文图像工作流提供了可直接调用的API接入点。
