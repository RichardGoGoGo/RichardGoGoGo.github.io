阿里巴巴发布Qwen-Image-3.0并开放API，该模型在多语言文字渲染方面支持12种语言，可在生成图像中准确排布跨语言文字内容；在复杂信息图（infographic）生成能力上有显著提升，适用于数据可视化、报告配图和多语言内容制作；已通过阿里云API向开发者开放商业调用，暂未发布权重。

> 12语言文字渲染能力对国际化内容创作和多语言教学材料的自动生成具有直接应用价值，填补了图像AI在精准多语言排版方面的能力短板。
