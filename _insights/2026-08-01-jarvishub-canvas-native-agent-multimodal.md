JarvisHub 是一个面向长程多模态创作任务的开源画布原生 Agent 框架（arXiv 2607.23588），代码发布于 GitHub（LYL1015/JarvisHub）。框架将可编辑画布同时作为 Agent 工作区、外部持久记忆与动作执行空间，通过全局规划、画布记忆和工具执行三层架构，实现多模态创作过程中的持续规划、迭代编辑与版本管理。系统支持图像、文本与代码多模态输入，解决了现有 Agent 在长程创作任务中频繁丢失上下文的核心问题。

> 将画布设计为 Agent 的持久记忆载体，为多步骤 AI 辅助创作工作流提供了一种结构化的架构参考。
