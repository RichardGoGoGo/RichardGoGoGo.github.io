## 0. 定位与适用范围

服务高校教师与实验室：工作营讲稿、课程课件、项目汇报、学术报告、对外路演。

按这个顺序做，每步有产物、有确认点：

| 步 | 产物 | 确认点 |
|---|---|---|
| 1 叙事 | `brief.md`（故事线 + 逐页表） | 用户确认提纲 |
| 2 页型与视觉 | `style.md`（风格文件）+ 每页页型 | 用户确认风格 |
| 3 成品 | `index.html` 或 `deck.pptx` + PDF 备份 | 自检通过 |
| 4 备注 | `notes.md` + 成品内备注 | 随成品交付 |

- 没有 brief 不排页；brief 没确认不定风格。用户明确说"直接做完"时，照样产出 brief 和 style，随成品一起交，并在回复里列出你替他做的假设。
- 改动先改 brief 或 style，再改页面。页面和 brief 不一致时以 brief 为准。
- 做浅译万道自己的演示时，语气、术语、色板遵循 实验室品牌规范（BRAND）。给老师做的课件归老师，风格随老师和学校；术语表照用。

## 1. 第一步：叙事

### 1.1 先问清五件事

一次问完，能从上下文推断的不再问，在 brief 里写明假设。

| 项 | 问什么 | 缺省处理 |
|---|---|---|
| 受众 | 谁在听，已经知道什么，可能抵触什么 | 必问 |
| 场合与时长 | 课堂 / 工作营 / 汇报 / 学术会议 / 路演，讲多少分钟 | 必问 |
| 讲还是读 | 现场讲为主，还是会后传阅、提交评审为主 | 按场合推断：现场讲默认讲为主，提交材料默认读为主 |
| 材料 | 全文、零散笔记，还是只有题目 | 按实际；只有题目时先列提纲请用户补事实 |
| 成品形式 | HTML、PPTX 或两者 | 按 3.1 推荐 |

### 1.2 写主旨和观众状态

- **一句话主旨**：≤30 字，是听众听完要记住的判断。写"介绍 X""X 的探索与实践"不算主旨。
- **起点 → 终点**：听众来之前知道/相信什么，听完之后知道/相信什么。
- **核心阻力**：什么让他们还没到终点。
- **听完要做的一件事**：批准、报名、选课、回去试、约下一次。

这四项写不出来，就回去问用户，不要开始排页。

### 1.3 选故事线

从 `references/narrative-structures.md` 选一条主线：

| 场景 | 默认结构 |
|---|---|
| 学术报告、答辩 | 问题 — 缺口 — 方法 — 证据 — 意义 |
| 课程课件 | 情境 — 问题 — 新知 — 示范 — 练习 — 小结 |
| 工作营、师资培训 | 目标 — 演示 — 动手 — 卡点 — 复盘 — 带走 |
| 项目汇报 | 结论先行：结论 — 进展 — 成果 — 风险 — 需要支持 |
| 对外路演、提案 | 痛点 — 现状为何不行 — 方案 — 证据 — 路线 — 请求 |

每页标一个角色：开场、铺垫、冲突、方法、证据、示范/练习、收束。一套 deck 只走一条主线。

### 1.4 定页数与节奏

- 讲为主：平均每页 1.5–3 分钟。90 分钟讲座约 30–45 页，不是 90 页。工作营的动手时间不按页算。读为主：页数按信息量定，每页仍只讲一件事。
- 每 5–8 页放一个节点页（章节、小结或提问）。
- 讲为主和读为主都要时，分成两份：讲的版本少字，另出读的版本（讲义）。不要做一份两头凑合的。

### 1.5 每页只讲一件事

- 页标题全篇用一种写法：短名词（课件、学术报告常用）或陈述句（汇报、路演常用）。
- **标题序列测试**：把全部页标题按顺序读一遍，没看过正文的人能复述故事线，才算通过。
- 一页有两件事，拆；一页讲不完一件事，拆。不靠缩小字号往里塞。
- 书面语改成讲的语言：页上留判断、关键词、数字、图；解释性的长句进备注。
- 每页都要说得出"这页让听众从什么变成什么"。说不出来的页，删或并。

### 1.6 写 brief

写入 `brief.md`，格式：

```markdown
# <演示标题>
- 受众：…　场合/时长：…　讲/读：…　成品：HTML / PPTX
- 一句话主旨：…
- 起点 → 终点：… → …　核心阻力：…　听完要做：…
- 故事线：<结构名>　标题写法：短名词 / 陈述句
- 假设（用户未说明、由你推断的）：…

| 页 | 角色 | 标题 | 这页让听众从…到… | 页型 · 视觉锚点 | 素材来源 | 时长 |
|---|---|---|---|---|---|---|
| 01 | 开场 | … | … | 封面 · 主视觉照片 | 用户提供 | 1′ |
```

交给用户确认。确认前只改 brief，不做页面。

## 2. 第二步：页型与视觉

### 2.1 给每页定页型

页型见 `references/page-types.md`：封面、议程、章节、大判断、证据（数据）、对比、流程、框架、时间线、案例、引文、满版图、示范、练习任务、讨论/提问、小结、致谢/问答、附录。

- 同类内容用同一页型、同一位置：所有章节页一个样，所有案例页一个样。同一页型最多连用 3 页。
- 每页一个视觉锚点（大数字、图、示意图、引文、实拍或大标题），只能一个。不画与内容无关的装饰插画；没有合适的图，用排版和大字做视觉。

### 2.2 定风格文件

模板和两个示例见 `references/style-file-template.md`。

- 来源按优先级：学校或会议的模板/VI → 用户已有的风格文件 → 新建。
- 一套 deck 只用一份 `style.md`。颜色、字体、字号、网格、容器、页眉页脚全部从它取；不混入之前任务或其他参考的视觉元素。
- 卡片、边框、分割线、圆角、阴影全篇一种系统。页与页的变化来自页型，不来自换框。
- 用户说不清要什么风格时，用真实标题做 3 张封面预览：一张稳妥、一张有性格、一张针对本题定制，差别要大。页面上不出现"方案 A""稳妥版"、风格名、文件名等内部字样，这些只写在给用户的消息里。用户选定后写成 `style.md`。

### 2.3 字号、留白与对比

以 1920×1080 为准。PPTX 用 13.33×7.5 英寸画布，pt = px ÷ 2。

| 元素 | HTML（px） | PPTX（pt） |
|---|---|---|
| 封面标题 | 96–144 | 48–72 |
| 页标题 | 56–80 | 28–40 |
| 正文（讲为主） | 36–48 | 18–24 |
| 正文（读为主） | 28–32 | 14–16 |
| 大数字 | 160–240 | 80–120 |
| 注释、来源、页码 | ≥24 | ≥12 |

- 标题字号至少是正文的 1.6 倍。层级靠字号和字重，不靠加框加色。
- 边距：上 ≥80、下 ≥72、左右 ≥100（px）。内容偏上、下方留白是正常的版面，不要为了"居中"把内容往下推。
- 远看 3 秒能看出先看哪里。有多个同样重的块在抢注意力，就删字或降权。
- 正文与背景对比度 ≥4.5:1。投影会冲淡浅灰和淡彩，浅底上的正文别用浅灰。
- 颜色：主色占大面积，辅色一个，强调色只给要点（≤10%）。
- 动效只在顺序有意义时用：逐条揭示、数字落定、图解分步。多数页不需要。

### 2.4 图文比例

- 讲为主：图多于字。常用：满版图 + 一行判断；左图右文约 6:4；大数字 + 一句解释。
- 读为主：字可以多，但用网格、表格、带标注的图组织，不贴段落。
- 照片可裁切铺满；截图、图纸、示意图完整显示，不裁不拉伸，放在纯色底上。
- 图上压字要有遮罩或纯色区，保证对比度。
- 数据图：一张图一个结论，结论写进标题；去掉多余网格线、3D 和默认图例；要强调的系列用强调色，其余用灰。

### 2.5 中文排版

- 字体只用可免费商用的：思源黑体 / Noto Sans SC、思源宋体 / Noto Serif SC、霞鹜文楷（均为 OFL）；数字与西文配 Inter、IBM Plex、JetBrains Mono 等 OFL 字体。不用方正、汉仪等商业字库，除非对方已有授权。
- 行长：标题 ≤16 字，正文 ≤28 字。标题在意群处手动断行，避免一个字单独成行。
- 行高：标题 1.2–1.3，正文 1.5–1.7。中文不用斜体，不压扁拉长，不加大字距。
- 全角标点；标题末尾不加句号；引号全篇统一一种。
- 中英文、数字之间留不留空格，全篇统一一种。
- 默认左对齐；只有封面、大判断页、引文页、提问页可以居中。
- 术语按 BRAND.md 术语表：课题负责人（不写 PI）、AI 视觉生成、工作营、LoRA / 模型训练等。

### 2.6 去掉 AI 味

- 版式：标题下不加装饰短横线；卡片不加单侧色条；不满屏堆同款卡片；不用紫色渐变白底；不给每页都做成海报。
- 文案：不写"不是 X，而是 Y"式反转句，不写故弄玄虚或喊口号的标题，不用"赋能、抓手、闭环、全方位"等空词。标题是在介绍这一页，不是替讲者抖包袱。
- 页上、备注里不能出现"思考过程""作为 AI""首先我需要"等草稿字样，也不能有 TODO、TBD、XXX、lorem、[待补] 等占位。

## 3. 第三步：成品

### 3.1 选 HTML 还是 PPTX

| | HTML 单文件 | PPTX |
|---|---|---|
| 适合 | 讲者自己放映；要动效、嵌视频、现场演示网页；线上分享 | 要交给对方改；学校或会议要求交 PPT；会场电脑只有 PowerPoint |
| 不适合 | 对方要逐字编辑 | 重动效、复杂交互 |

两种都要时，以 `brief.md` + `style.md` + `notes.md` 为共同来源分别生成，不要把一种截图贴成另一种。

### 3.2 HTML 做法

骨架和键位见 `references/html-stage.md`。要点：

- 单个 `.html`，CSS/JS 内联，无构建步骤；图片放 `assets/` 用相对路径。
- 固定 1920×1080 舞台，整体等比缩放，留黑边；不做响应式重排。
- 切页用可见性加类名，不用 `display` 切换。
- 离线可用：字体子集化后内联，或只用本地回退字体栈并断网预览一次。不依赖 CDN。
- 键盘翻页、F 全屏、S 演讲者视图（备注、计时、下一页）、N 排练用备注条。
- `@media print` 一页一张，另存 PDF 作备份。
- 备注写在每页 `data-notes` 里。

### 3.3 PPTX 做法

- 生成、编辑、校验 .pptx 文件的操作交给环境里的官方 pptx skill（名字通常是 `pptx` 或 `anthropic-skills:pptx`；环境里没有时告诉用户，改出 HTML + PDF）。本 skill 负责给它输入：`brief.md`、`style.md`、`notes.md` 和每页页型。
- 画布 16:9（13.33×7.5 英寸），字号按 2.3 表的 pt 列。
- 文字都是可编辑文本框；表格和柱、线、饼图用 PowerPoint 原生对象，不贴截图。
- 备注写进每页备注区，不放在页面上。
- 字体在对方电脑上渲染：用思源黑体时提醒对方安装，或导出时嵌入字体；不确定时正文回退微软雅黑（Windows）/ 苹方（Mac），文本框留约 10% 余量。另出一份 PDF 兜底。
- 用学校或会议模板时，先看模板有哪些版式，把页型对应到版式；模板占位比内容多时整组删除，不留空壳。

### 3.4 渲染后逐页看图

- 出图后逐页看图，不凭代码判断：HTML 用浏览器按 1920×1080 截图；PPTX 转 PDF 再转图片。先查文字溢出和截断，再查遮挡（页码、角标、来源压住正文）、图片未加载、对比度不足、占位残留。只重做有问题的页。

## 4. 演讲备注

写法见 `references/speaker-notes.md`。每页五个字段：

- **意图**：这页让听众从什么到什么（抄 brief）。
- **讲稿**：讲者要说出口的话。第一次讲或正式场合写口语全文；熟手写 3–5 句要点。
- **过渡**：接下一页的一句话。全部过渡句连起来读，应该能听出故事线。
- **不说**：容易跑偏、超时或有风险的话（可选）。
- **互动**：提问、动手指令、计时（课程和工作营必填）。

页上字多，说明讲稿放错了地方：把字搬进备注。

## 5. 自检清单

交付前逐条过。发现问题就改，自检加修改最多 3 轮；3 轮后仍有问题，列清单交给用户定。

叙事
- [ ] 一句话主旨写得出，每页都在推进它
- [ ] 标题序列测试通过；标题写法全篇统一
- [ ] 没有"只能看、不能讲"的页：每页说得出它让听众从什么到什么；只有几个字、意思没说完的页已补或并
- [ ] 页数与时长匹配，节点页齐全

视觉
- [ ] 只用了一份风格文件里的元素；同类页版式一致；页码、页眉位置统一
- [ ] 最小字号达标；无溢出、无遮挡、无横向滚动
- [ ] 每页一个视觉重心；对比度够
- [ ] 无占位残留、无草稿字样、无页面内部标签

事实
- [ ] 数据、引语、日期、机构名、作品署名有出处且核对过；没有编造的数字或引语
- [ ] 未公开成果没有写成既成事实；敏感项目已脱敏；学生作品和反馈已获同意或匿名

成品
- [ ] HTML：断网打开字体正常；翻页、全屏、演讲者视图、打印可用
- [ ] PPTX：PowerPoint 能打开；文字可编辑；每页有备注；PDF 备份已出

## 6. 输出要求

在用户指定的位置建目录（未指定时用当前项目下的 `deck/`）：

```text
deck/
├── brief.md      提纲：主旨、观众状态、故事线、逐页表
├── style.md      风格文件
├── notes.md      演讲备注，页号与成品一一对应
├── index.html    HTML 成品（选 HTML 时）
├── deck.pptx     PPTX 成品（选 PPTX 时）
├── deck.pdf      PDF 备份
└── assets/       图片等素材
```

最终回复包括：成品路径；页数与预计时长；所用故事线和风格；自检结论与未解决项；放映方法（快捷键、双屏用法、如何导出 PDF）。

不做的事：不做整页 AI 生图拼成的纯图片 PPT（不能编辑、中文易错字、内容要发到外部服务；概念配图只当局部素材，文字仍由排版完成）；不生成或描摹机构 logo，用对方提供的文件；不编造日期、数据、引语、听众反应。
