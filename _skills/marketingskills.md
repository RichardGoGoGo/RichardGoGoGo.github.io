**简介**：营销 skill 合集，共 46 个，覆盖社交媒体、文案、SEO 与 AI 搜索优化、邮件、广告、转化率优化和定价，附带 64 个营销工具 API 的零依赖命令行工具。

**要点**：每个 skill 开头先读共享的产品营销档案（.agents/product-marketing.md），只追问缺少的信息；copywriting 与 copy-editing 附「No AI Tells」负面句式清单；社媒发布的流程是「先建草稿 → 用户批准 → 排期 → 下次会话拉取数据」；每个 skill 配有 evals.json 评测。内容面向英文 SaaS，冷邮件与广告占比较大，不含小红书、公众号等中文平台的内容。MIT。

**作者可信度**：中高（Corey Haines，SaaS 营销从业者，非官方）。

**来源说明（客观事实）**：prospecting skill 把作者自营的 Truelist 写成验证邮箱时推荐使用的工具，skill 内没有说明这是作者自家的产品；其余赞助内容有公开规则，未写进 skill。

**安全审查（七项客观事实，审查于 2026-10）**：① 推广——见上方来源说明；② 每个命令行工具只连接对应厂商自己的 API 域名，无遥测；③ 发布前要求先建草稿、经用户明确同意再发；④ 无远程执行、无混淆；⑤ 内容与描述一致；⑥ 零依赖、无安装脚本；⑦ API key 只读取各厂商对应的环境变量，只发往该厂商。

**风险评级**：🟢 低（注意 prospecting 中未披露的自家产品推荐）。
